Comment installer l’application ? +

Télécharge l’APK sur ton téléphone Android, ouvre le fichier puis suis les étapes affichées. Android peut demander d’autoriser temporairement l’installation depuis le navigateur ou le gestionnaire de fichiers.

WORLD-AI répond déjà aux messages ? +

Pas encore. La conversation et la saisie sont présentes dans l’application, mais les réponses d’une IA ne sont pas encore connectées. Le sélecteur d’IA indique « Ajoute prochainement ».

Comment changer l’icône ? +

Dans l’application Android, ouvre le menu puis Paramètres. La section « Icône de l’application » permet de sélectionner l’un des trois visuels.

Comment se passent les mises à jour ? +

L’application vérifie les releases publiées sur GitHub et peut proposer une version plus récente au démarrage. Tu peux également la télécharger depuis le bouton de cette page.
